# Fortress balance roadmap

기준일: 2026-08-03
대상: OpenFront Fortress fork

## 1. 이번 패스에서 확정한 규칙

### 영토와 개발

- 영토 크기만으로 전투 손실·점령 속도를 낮추지 않는다.
- 개발 보너스는 완공된 도시·공장·항구의 **총 레벨 투자량**으로만 발생한다.
- 개발 요구량은 `12,000 + 영토 타일 × 0.55`다.
- 최대 보너스는 국내 수입 +20%, 상업 수입 +8%, 증원 +15%, 작전 속도 +5%다.
- 내부개발은 직접적인 사상자 교환 배율을 제공하지 않는다.

### 군사 품질

- HUD의 징집군~근위군 `×1.00~×2.00` 표시는 유지한다.
- 전투 계산에는 `표시 품질^0.55`를 사용한다.
- 사상자 교환 modifier는 `0.82~1.22`, 작전 속도 modifier는 `0.94~1.06`으로 제한한다.
- 지도 교전과 서로 마주친 공격대 상쇄가 같은 유효 품질 함수를 사용한다.

### 경제와 지원

- 공장과 항구는 각각 독립된 가격 누적 풀을 사용한다.
- 열차·무역선 수익에 개발 기반 상업 배율을 적용한다.
- 정복 골드는 Bot·Nation·Human 모두 보유 골드의 35%다. 공격하지 않은 Human의 기존 무보상 규칙은 유지한다.
- 동맹 골드 지원은 `max(125,000, 보유 골드 20%)`를 남긴 뒤 잉여의 20%를 전송한다.

## 2. 다음 밸런스 패스의 측정 기준

수치 변경은 아래 지표를 deterministic fixture와 실제 경기 로그에서 함께 확인한 뒤 진행한다.

| 영역 | 핵심 지표 | 1차 목표 범위 |
|---|---|---|
| 초반 확장 | 첫 도시/공장/항구 완공 시점 | 90~210초 |
| 성장 선택 | 도시·공장·항구별 투자 회수 시간 | 90~180초 |
| 군사 품질 | 동일 병력 최고/최저 등급 교환 우위 | 1.35~1.50배 |
| 방어 시설 | 동일 비용 공격 병력을 지연하는 시간 | 25~60초 |
| 상륙 | 1:1 호위 조건 상륙 병력 생존율 | 40~60% |
| 정복 복리 | 3개 소국 연속 정복 후 자금 증가율 | 초기 자금의 100% 이내 |
| 동맹 지원 | 지원 후 제공자가 즉시 지을 수 있는 최소 시설 | 1개 이상 |
| 경기 종결 | 승세 확정 후 종료까지 걸리는 시간 | 4~8분 |

## 3. 후속 구현 단계

### Phase A — 밸런스 계측 기반

1. `scripts/fortress-balance-report.mjs`에서 다음 시나리오를 JSON/Markdown으로 출력한다.
   - 5K, 25K, 80K, 200K 영토의 개발 투자 곡선
   - 군사 등급별 유효 품질과 교환 modifier
   - 도시·공장·항구 1~8레벨 누적 비용
   - 열차·무역선 거리별 수익
   - 정복·동맹 지원 전후 자금
2. 게임 종료 통계에 첫 시설 건설 tick, 첫 공격 tick, 상륙 시도/도착 병력, 시설별 지출을 기록한다.
3. 지도·난이도별 결과를 분리한다. 전체 평균 하나로 합치지 않는다.

완료 조건: 동일 seed에서 보고서가 항상 같은 값을 내고, 밸런스 상수 변경 시 diff가 수치로 드러난다.

### Phase B — 초반 경제와 시설 역할

- 도시: 최대 병력·훈련·군사 등급 중심
- 공장: 개발 투자·철도 운영·내륙 상업 중심
- 항구: 해상 상업·함대 회복·상륙 물류 중심
- 각 시설 업그레이드의 다음 효과와 회수 예상 시간을 건설 UI에 노출한다.
- 공장·항구가 없는 내륙/도서 지도에서 특정 전략이 봉쇄되지 않도록 지도별 보정값을 분리한다.

검토 후보:
- 도시의 최대 병력 +250K와 훈련 수용량 +200K 차이
- 공장 레벨별 열차 생성 기여
- 항구 레벨별 무역선 수익·함대 수리·상륙 준비 시간

### Phase C — 전선과 방어 시설

현재 Defense Post는 낮은 비용으로 넓은 범위에 큰 배율을 제공한다. 다음 fixture를 먼저 만든다.

- 평지/산악/방사능 지형별 동일 병력 교전
- 방어소 0/1/2개 중첩 여부
- 단일 전선과 다중 전선의 실질 효과
- 포위·우회 시 방어소 가치

초기 조정 후보는 방어 보너스와 점령 지연 보너스를 분리하고, 중첩은 최대 1개만 적용하는 방식이다. 목표는 방어소가 공격을 멈추는 영구 장벽이 아니라 재배치 시간을 사는 시설이 되게 하는 것이다.

### Phase D — 해군과 상륙

다음 항로 길이별 fixture를 고정한다.

- 짧은 해협 40~80타일
- 중거리 100~220타일
- 장거리 300타일 이상

각 항로에서 무호위, 1:1 호위, 2:1 호위를 비교하고 아래를 기록한다.

- 출항 병력
- 수송선 격침 수
- 해안 도착 병력
- 교두보 10초/30초 유지 여부
- 방어 전함과 항구 레벨

조정 레버는 수송선 HP, 전함 재장전, 호위 우선순위, 상륙 후 초기 점령 속도다. 한 번에 하나만 변경한다.

### Phase E — 핵·SAM·후반 종결

- Atom/Hydrogen/MIRV의 골드당 제거 병력과 영토 손실을 동일 fixture로 비교한다.
- SAM L1~L5의 비용, 범위, 요격률, 회수 시간을 측정한다.
- Doomsday Clock은 영토 점유율뿐 아니라 남은 유효 전투력과 연동할지 별도 실험한다.
- 승세가 확정된 뒤 방어 시설과 핵 비축 때문에 경기만 길어지는 구간을 측정한다.

### Phase F — AI와 난이도

난이도는 숨은 전투 배율보다 의사결정 품질로 분리한다.

- 도시/공장/항구 투자 비율
- 훈련 수용량 대비 동원 병력
- 상륙 전 호위 확보
- 동맹 지원 reserve 준수
- 핵 목표 선정과 SAM 회피

Easy~Impossible의 수치 보정은 위 행동 차이로 부족한 부분에만 최소 적용한다.

## 4. 변경 운영 규칙

- 한 PR에서 독립 레버는 최대 2개만 조정한다.
- 모든 수치 PR은 이전/이후 시나리오 표를 포함한다.
- 단위 테스트, 3개 viewport 브라우저 스모크, Pages 실배포를 모두 통과해야 병합한다.
- UI에 표시되는 배율과 실제 계산 배율이 다르면 둘 다 명시한다.
- 평균 승률만 보지 않고 전략, 지도, 시작 위치, 경기 길이별 분포를 함께 본다.

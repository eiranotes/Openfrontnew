# Touch selection and UI polish direction

Reference mode: structured adaptation.

- Preserve the live map as the primary surface.
- Use one-tap country selection with immediate pressed/selected feedback.
- Use a non-modal, compact command rail on mobile instead of a tall information card.
- Keep one primary action prominent; demote chat, emoji, trade, and metadata.
- Use restrained surfaces: small radii, one cool neutral family, one accent family, no decorative glow.
- Keep frequent controls at least 44px with visible pressed states.
- Collapse secondary country details behind an explicit details affordance.

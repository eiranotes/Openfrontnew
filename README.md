# OpenFront Fortress bootstrap

This repository starts empty and bootstraps the public OpenFrontIO source at a
pinned upstream commit. The workflow then applies the Fortress balance patch,
runs targeted tests and a TypeScript build, commits the populated source tree,
and deploys the static single-player build to GitHub Pages.

Expected play URL after the first successful workflow:

`https://eiranotes.github.io/Openfrontnew/`
